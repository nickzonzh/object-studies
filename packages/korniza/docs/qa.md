# KORNIZA v1 hardening QA

Verified 23 September 2026 on Windows with Chromium, React 19.3 and the installed Vite 7 toolchain. This is the current acceptance record; earlier visual-design notes are preserved in `docs/archive/design-qa.md` in the repository.

## Scope and result

All six locked variants remain present in canonical order. No ornament paths, material palettes or texture assets were redesigned in this pass. All 14 locked geometry/texture files were compared byte-for-byte against the starting workspace and are unchanged. Shared above-left lighting, lower-right wall shadows, fixed corner geometry and recessed openings remain consistent. Modern Black intentionally retains a shallower shadow; gold retains a stronger material response than timber.

**Ready for local package consumption and release preparation.** Public publication remains a separate step: license selection, package name/version confirmation and final cross-browser/device review.

## Before / after

| Before | Hardened behaviour |
| --- | --- |
| Six duplicated pointer handlers | One RAF-batched hook; geometry reads occur once per rendered update; no React state changes |
| Rails scaled with viewport width | Rails scale with the component container, keeping the contact-sheet proportions at 520px and capping at the original maxima |
| Prototype-oriented exports and `ratio` | `Frame`, `FrameImage`, `FrameProps`, `FrameVariant`, `frameVariants`; explicit `variant` and `aspectRatio` |
| Contact sheet generated by an ignored output script | Persistent React collection view with identical-content and ratio controls |
| Styles depended on page-level box sizing | Library-scoped box sizing; verified without demo CSS |
| Image intrinsic sizing could influence grid layout | Optional image helper fills the opening independently of intrinsic dimensions |
| Demo-only Vite output | Separate ESM library, declarations, CSS, exports and local tarball |
| Source CSS imports leaked into declarations | Build finalizer removes source-only imports and provides a typed stylesheet export |

## Interaction and accessibility

**67 interaction/rendering checks passed**, including all variants' pointer response, unchanged frame bounds, leave/cancel reset, dynamic reduced-motion reset, reduced-motion suppression, touch suppression, disabled/re-enabled lighting, unique SVG IDs and responsive bounds.

Enter and Space activate the live React card. State survives an aspect-ratio change. Demo controls have explicit accessible labels, visible focus indicators and normal keyboard behaviour. Images have meaningful alt text; ornament is hidden from accessibility APIs and ignores pointer events. The supporting text uses dark muted colors on the light wall. No animations or light movement are required to access content.

The isolated package consumer additionally verified oversized-content scrolling, focus revealing the final button, automatic-height text, consumer `preventDefault()` suppressing light, a video poster/control slot and unchanged rail thickness at a fixed component width across viewport changes. Actual video playback is not claimed.

## Package and performance

- TypeScript, demo production build and library build pass. The production preview also passed 20 content/viewport combinations with no failed asset requests, runtime errors or overflow in the practical examples.
- `npm pack --ignore-scripts=false` builds an allowlisted package; local installation into an independent consumer succeeds.
- Independent browser render without demo CSS and server rendering of all six variants pass.
- Consumer typechecking includes `noUncheckedSideEffectImports`, ensuring the stylesheet and declaration graph resolve.
- React and JSX runtime remain external peers. No raster frame assets, demo photographs, page reset or React runtime in the library.
- Library payload: approximately 19.1 kB ESM (5.6 kB gzip) plus 303.6 kB self-contained CSS/SVG textures (21.6 kB gzip). The larger raw CSS is embedded vector texture data, not network image dependencies.
- No polling or continuously running effects. Existing SVG geometry reuse and instance-safe IDs are preserved. No speculative memoization or lazy-loading machinery added.

The first consumer attempt was served through the parent demo root and resolved two React copies; serving the independently installed consumer from its own Vite root resolved the test-harness issue. It is not a bundled-React issue: the library imports React externally.

## Reproduce

npm ci
npm run check
npm pack --ignore-scripts=false
npm run dev
# With the optional Playwright CLI available:
playwright-cli -s=korniza open http://127.0.0.1:5173
playwright-cli -s=korniza run-code --filename=scripts/visual-qa.js
playwright-cli -s=korniza run-code --filename=scripts/interaction-qa.js

Create `output/playwright/hardening/` before running the capture scripts. The scripts are checked in; generated captures stay ignored. The CLI scripts throw on failed checks. ## Remaining limits

No known blocking component defect in tested conditions. Real Safari/Firefox, physical iOS/Android devices, assistive-technology sessions and native Windows display scaling have not been verified in this pass. DPR/CSS zoom tests approximate fractional rendering, not native OS scaling. Native video playback/streaming and arbitrary third-party embeds are outside this pass; the DOM slot is verified.

Consumers own child typography, padding, contrast, focus semantics and image cropping. Oversized content intentionally scrolls; `aspectRatio="auto"` suits long reading blocks. Use an outer width of at least 220px and leave room around projecting ornament/shadows. Modern CSS container-query/mask support is required. Invalid ratios are outside the contract.

The repository remains private-package guarded and unlicensed pending the owner's license decision. No commit, push, deployment or publication was performed.
